# README showcase evidence

## Scope

Documentation, demo fixtures/recording, a hand-authored SVG, and package description only. No CLI behavior or dependency change. The release number remains owned by release-please.

## Plan versus observed behavior

- The repo plan described reading config section names only. The actual 3.0.1 binary also discovers section names in `~/.aws/credentials`, with `AWS_CONFIG_FILE` and `AWS_SHARED_CREDENTIALS_FILE` overrides. Confirmed against `src/config.rs`, the migration record, and an isolated credentials-only profile selection. README and diagram describe both files.
- The requested dev/stage/prod demo uses explicit `AWSPICK_GROUP_RULES='dev=dev;stage=stage;prod=prod'`. Built-in groups are prod/stg/dev/preprod, not stage. README distinguishes the defaults from the custom demo rule.
- The actual CLI has no `--no-rc`. Redirecting/evaluating stdout still edits rc. README states this before the reference material and in the file-safety section.
- Default backup retention is 2, beside the rc file. An isolated series of switches confirmed 2 matching `.bashrc.bak-*` files remain. The first matching literal assignment controls the already-set shortcut; the migration record documents multiple-assignment edge cases.
- Main's test workflow is `release-please.yml`; `ci.yml` excludes main pushes. The README's CI badge therefore points at the main workflow, not a nonexistent main run of CI.
- The previous v3.0.1 release run already successfully pushed the Homebrew formula and published through crates.io Trusted Publishing. Those are not first-time capabilities introduced by this documentation release. Prior evidence: [run 42249201703](https://github.com/KKamJi98/aws-profile-pick/actions/runs/42249201703), including non-skipped `push Formula/awspick.rb`, `crates-io-auth-action`, and `cargo publish --locked` steps.

## Demo checks

- Recorded from the real 3.0.1 release build of this documentation branch with VHS 0.12.1. No output replacement or post-recording text editing.
- Synthetic HOME, config, empty credentials, rc files, fictional SSH config, and `$ ` prompt. Inherited AWS values, startup hooks, and ZDOTDIR are cleared with `env -i`. No AWS CLI/API calls.
- Final GIF: 20.04 seconds, 1100 x 690, 185028 bytes. MP4 is generated by the same tape.
- Extracted final-GIF samples at 2-second intervals, plus the final result frame. Inspected full table, regex selection, backup/rc/shared-file summary, and `echo "$AWS_PROFILE"` result. No real identity, account ID, hostname/IP, profile name, company data, or token was visible. Text contrast and clipping were checked on the final light-theme recording.
- The real `.zshrc`, `.aws/config`, and `.config/awspick/profile` contents were never read. Nanosecond mtime metadata matched before/after recording.
- Reproduction instructions and safety boundary are in [demo/README.md](demo/README.md). The safe entry point is `bash docs/demo/record.sh`, not a direct tape invocation.

## Documentation checks

- Three quick-start scenarios were exercised with the documented wrapper in isolated bash and zsh sessions. The displayed stdout checks are actual results. A nonexistent profile exits 1 through the wrapper.
- Regex menu bytes in README were copied from the captured stderr, not reconstructed by hand.
- The companion-tools section uses the shared family source without changing its wording or order.
- Package metadata already contained readme, keywords, categories, homepage, and repository. Only the description needed alignment with the new one-line README introduction.
- Existing golden fixtures remain unchanged. No source bugs were fixed in this documentation scope; existing write/concurrency caveats remain described in the migration record.
